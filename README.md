# Persist-Godot

**Save/load system with context-scoped node persistence**

[![Godot](https://img.shields.io/badge/Godot-4.7%2B-478cbf?logo=godot-engine&logoColor=white)](https://godotengine.org/download)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Status](https://img.shields.io/badge/status-WIP-orange)](#install)

## Features

- **Save / Load Management** - Using small and secure binary encoding
- **Persistent Properties Between Scenes** - Unload and reload a scene without changing select properties on nodes
- **Save File Backup System** - Ensure players don't experience progress loss or save corruption 

## Install / Usage
 
After adding the latest [Release](../../releases/latest) to your project, enable the addon in your project settings.
 
> **Note:** Persist is still in early development (WIP). APIs and features may change before a stable release.
